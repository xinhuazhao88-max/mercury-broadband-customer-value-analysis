# Project Management

This project was managed using Jira and Confluence to structure the Business Analysis workflow.

## Jira

Jira was used to break the business problem into manageable work items and track progress through a Kanban workflow.

### Project Structure

**Epic**
- Improve Broadband Customer Value

**Work Items**
- Analyse Broadband ARPU Drivers
- Analyse Broadband Customer Segments

**Key Analysis Tasks**
- Review Broadband ARPU Data
- Analyse Quarterly ARPU Trend
- Identify Potential ARPU Drivers
- Document Business Findings
- Review Customer Connection Data
- Analyse Customer Growth Trends
- Compare Product Adoption
- Identify Customer Segment Opportunities

### Workflow

The work items were managed using the following workflow:

**To Do → In Progress → In Review → Done**

This helped structure the analysis process and track completion of each task.

## Confluence

Confluence was used to document the business analysis and communicate the findings.

The documentation included:

- Executive Summary
- Business Problem
- Project Objectives
- Data Analysis
- Business Findings
- Business Insights
- Recommendations

## Business Analysis Approach

The overall workflow was:

1. Define the business problem
2. Break the problem into analytical tasks
3. Analyse the data
4. Identify trends and drivers
5. Document findings
6. Develop business recommendations
